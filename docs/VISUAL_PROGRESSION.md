# Wave Arena Visual Progression

Status: enforced
Last reviewed: 2026-08-25
Runtime SSOT: `src/game/visual-system.js`

## 목표

강화가 수치만 오르는 것이 아니라 전장에서 즉시 읽히도록 캐릭터, 몬스터, 방어 기지, 포탑, 발사체의 **실루엣·재질·코어·무기 문법**을 함께 진화시킨다. 외부 비트맵이나 런타임 네트워크 없이 90° 회전, 모바일, 오프라인 PWA를 동일하게 지원한다.

## 6개 시각 등급

| 등급 | 핵심 재질 | 실루엣 변화 | 발사체 |
|---|---|---|---|
| FIELD | 도장 강철·황동 | 기본 장비·단일 받침 | slug |
| VANGUARD | 은빛 합금 | 견갑·파일런 | bolt |
| RELIC | 보라 유물 합금 | 투구·다중 총열 | lance |
| ARCANE | 청록 에너지 장갑 | 동력 코어·궤도 부품 | plasma |
| CELESTIAL | 금빛 성역 장갑 | 왕관·날개·이중 레일 | comet |
| GENESIS | 백색 창조 합금 | 완전 장갑·다중 오비탈 | nova |

등급 안의 3개 변형은 문장 수, 파일런 수, 코어 크기, 트림 배치를 바꾼다. 따라서 같은 등급 안에서도 연속 레벨의 서명이 중복되지 않는다.

## 진화 계약

- 아군: 일반 강화, 무기, 방어구를 각각 0~15로 해석한다. 일반 강화는 코어·기지, 방어구는 흉갑·견갑·투구, 무기는 라이플과 발사체 형상을 바꾼다.
- 몬스터: 스테이지 상승을 16개 시각 랭크로 압축한다. 상위 랭크는 견갑, 투구, 반응로, 글레이브/보이드 블레이드가 추가된다. 보스는 전용 팔레트·크러셔·날개·왕관을 사용한다.
- 방어 기지: 강화 0~15 각각 고유 서명을 갖고, 성벽 높이·탑 수·중앙 keep·방어막·오비탈이 단계적으로 증가한다.
- 일반 포탑: 15단계 전부 고유 서명. 기존 소재별 몸체 위에 등급 재질 받침, 1~3 문장, 최대 4 파일런, 최대 4 오비탈을 조합한다.
- 연사/레이저/에너지: 각각 10/6/5단계 전부 고유 서명. 종류 고유 실루엣과 충전 상태는 LOD에서도 보존한다.
- 발사체: slug → bolt → lance → plasma → comet → nova의 6형. 고단계일수록 잔상 길이, 날개, 위성 코어, 외곽 레일이 추가된다.

## 성능 규율

1. 등급 해석 결과는 `Map`에 캐시하고 `Object.freeze`한다. 프레임 루프에서 팔레트·프로파일 객체를 재생성하지 않는다.
2. 발사체는 gradient와 shadowBlur를 쓰지 않고 선·원·볼록 다각형만 사용한다. 합성 레이어는 최대 6개다.
3. 연사탄은 고밀도에서 광역 halo와 위성 코어를 생략한다.
4. 적 18 이상·구조물 28 이상이면 얼굴·오비탈·추가 파일런만 줄이는 중간 LOD를 사용한다. 적 45 초과·구조물 30개 이상이면 silhouette LOD와 DPR 1.25 상한을 사용한다. 기지는 3개 박스, 포탑은 핵심 몸체·방향·코어만 남긴다.
5. reduced-motion에서는 캐릭터 오라와 불필요한 파티클을 생략한다.
6. 그래픽 변경은 20적·30+ 구조물의 DPR 1.5 중간 LOD 장면과 60적·30+ 구조물의 dense 장면을 모두 정상/CPU 4배 제한에서 통과해야 배포 가능하다.

## 자동 검증

`visualContractSnapshot()`은 캐릭터 16, 기지 16, 일반 포탑 15, 연사 10, 레이저 6, 에너지 5단계의 고유 ID와 6개 발사체 형상, 최대 레이어를 반환한다. smoke test는 중복 서명과 레이어 초과를 실패 처리한다. 시각 품질은 4개 기준 viewport 캡처로 별도 확인한다.
